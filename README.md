## 🌟 ساختار ماژول‌ها و فایل‌های کلیدی

### ۱. فایل‌های مستقل PHP
- **`install.php`**: اینستالر تعاملی تحت وب برای ایجاد خودکار پایگاه‌داده MySQL/SQLite، ساخت جدول‌ها، ایندکس‌ها و درج حساب اولیه مدیر سیستم (`Mohusyn`).
- **`config.php`**: فایل پیکربندی هسته اتصال به دیتابیس (MySQL PDO و SQLite fallback)، مدیریت نشست (Session) و متدهای کمکی.
- **`login.php`**: صفحه ورود مستقل با حفظ تم اختصاصی دارک آبسیدین و اعتبارسنجی هش‌های امنیتی.
- **`register.php`**: صفحه ثبت‌نام چندمرحله‌ای با ثبت اطلاعات کامل (نام، شماره تماس، ایمیل، استان و شهرهای ایران، تاریخ تولد، عنوان شغلی، مهارت‌ها و تایم‌لاین روتین شبانه‌روز).
- **`dashboard.php`**: داشبورد مستقل کاربر شامل دیلی پلنر ساعتی، تقویم شمسی، درصد پیشرفت، یادداشت‌ها و ثبت دلیل عدم انجام تسک‌ها.
- **`admin.php`**: پنل اختصاصی مانیتورینگ مدیر با تحلیل شاخص‌های کلیدی اعضا، انتصاب وظایف به کاربران و خروجی مستقیم اکسل/CSV.
- **`web.config`**: پیکربندی بهینه‌سازی‌شده برای وب‌سرورهای Microsoft IIS (پشتیبانی از FastCGI، قوانین Rewrite، امنیت و MIME types فونت‌های فارسی).

### ۲. دیلی پلنر ساعتی و تقویم شمسی (Hourly Planner & Jalali Calendar)
- برنامه‌ریزی زمان‌بندی‌شده از ساعت ۰۶:۰۰ صبح تا ۲۳:۰۰ شب (فرمت ۲۴ ساعته استاندارد).
- محاسبه بلادرنگ درصد پیشرفت روزانه (۰ تا ۱۰۰٪).
- یادداشت‌های اختصاصی روز و پیگیری عادات روزمره (هیدراتاسیون، ورزش، خواب کافی).
- ناوبری سریع در روزهای ماه با محاسبه دقیق کبیسه‌ها و ماه‌های ۲۹ تا ۳۱ روزه شمسی.

### ۳. تحلیلگر هوشمند عادات کاربر (In-House AI Habits Analyzer)
- ثبت هوشمند دلایل تعویق و عدم تکمیل هر تسک در دسته‌های:
  - اهمال‌کاری و مقاومت ذهنی (Procrastination)
  - اولویت دادن به درخواست‌های دیگران (Prioritizing Others)
  - کمبود زمان و خطای تخمین (Time Shortage)
  - افت انرژی و خستگی فیزیکی (Low Energy)
  - حواس‌پرتی با شبکه‌های اجتماعی و موبایل (Digital Distraction)
  - موانع و چالش‌های بیرونی (External Blockers)
- ارائه نمودار تحلیلی ماهانه از درصد عادات سازنده در برابر الگوهای بازدارنده.
- تولید خودکار **برنامه جبرانی هوشمند هفتگی** به همراه توصیه‌های ذهنی و راهکارهای غلبه بر خستگی.

### ۴. اهداف دوره‌ای، روتین روزانه و آزمون تیپ‌شناسی (Career Goals & Personality)
- ثبت و مدیریت اهداف شغلی در بازه‌های هفتگی، ماهانه، فصلی (Q1)، شش‌ماهه (H1/H2) و سالانه به همراه نوار پیشرفت درصدی.
- مدیریت تایم‌لاین شبانه‌روز کاربر (ساعت بیداری، شروع کار عمیق، ناهار و استراحت، باشگاه، زمان خواب).
- **آزمون تیپ‌شناسی بهره‌وری**: تعیین سبک کاری (استراتژیست تحلیلی، مجری پرشتاب، طراح خلاق، سازمان‌دهنده منعطف) همراه با نقشه راه تقویت تمرکز.

### ۵. پنل مانیتورینگ و خروجی گزارش‌ها (Admin Monitoring & Excel Export)
- مشاهده جدول کامل مشخصات کاربران، شهرهای محل سکونت، موقعیت شغلی و مهارت‌ها.
- مشاهده بلادرنگ آمار تسک‌ها و درصد پیشرفت هر عضو تیم.
- قابلیت اختصاص مستقیم تسک و ماموریت با تعیین ساعت دقیق و سطح اولویت به هر یک از اعضا.
- **دکمه خروجی اکسل / CSV با یونیکد UTF-8 BOM**: تضمین نمایش بدون ایراد و بدون به‌هم‌ریختگی حروف فارسی در نرم‌افزار Microsoft Excel.

## 🚀 راهنمای نصب و راه‌اندازی

### الف) اجرای وب‌اپلیکیشن در محیط Node.js / Vite:
```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه با لایو پریویو
npm run dev

# بیلد نهایی برای پروداکشن
npm run build
```

### ب) نصب و راه‌اندازی با PHP و وب‌سرور (IIS / Apache / Nginx):
1. محتویات پروژه یا فایل فشرده `taskrooz-source.zip` را در مسیر روت وب‌سرور قرار دهید.
2. مرورگر خود را باز کرده و به آدرس زیر بروید:
   ```
   http://localhost/install.php
   ```
3. اطلاعات پایگاه داده MySQL خود (یا انتخاب گزینه SQLite داخلی) را وارد کنید.
4. با فشردن دکمه **«راه‌اندازی و ایجاد ساختار دیتابیس»**، تمامی جدول‌ها به طور خودکار ساخته شده و حساب کاربری ادمین (`Mohusyn`) فعال می‌شود.
5. پس از پایان نصب، می‌توانید از طریق `login.php` یا `index.html` وارد سامانه شوید.
