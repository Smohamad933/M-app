# تسک‌روز (TaskRooz) 🚀
### سامانه جامع مدیریت تسک روزانه و وظایف تیمی (بر مبنای PHP و سازگار با IIS)

نرم‌افزار مدرن، ریسپانسیو و خام (بدون داده‌های نمونه ساختگی) برای مدیریت کارهای روزانه، تمرکز عمیق، و پایش فعالیت‌های اعضای تیم؛ طراحی شده با دو نمای **داشبورد حرفه‌ای دسکتاپ** و **شبیه‌ساز موبایل (Mobile PWA)**.

---

## 🌟 امکانات و تغییرات جدید

1. **نرم‌افزار کاملاً خام و آماده استفاده**:
   - صفر تسک تستی؛ سیستم با دیتابیس تمیز و آماده ورود تسک‌های واقعی شما آغاز به کار می‌کند.
   - حساب مدیر اولیه سیستم:
     - **نام کاربری**: `admin`
     - **کلمه عبور**: `admin` (یا `admin123`)

2. **داشبورد دسکتاپ قدرتمند (Desktop Dashboard)**:
   - سایدبار شکیل RTL با نمایش اطلاعات کاربر جاری، نقش سیستم، و دسترسی به تمام ماژول‌ها.
   - هدر دسکتاپ با تاریخ روز هجری شمسی، فیلتر تسک‌های اعضا، جستجوی زنده، و دکمه تسک جدید.
   - نماهای چندگانه تسک‌ها:
     - **فهرست ستونی (List View)**
     - **کانبان بورد تعاملی (Kanban Board)**
     - **تقویم ماهانه هجری شمسی (Calendar View)**
   - کارت‌های آماری شاخص کلیدی (KPI) برای بازدهی روز، ساعت‌های تمرکز عمیق، و استریک روزانه.

3. **پنل مدیریت کاربران و اعضای تیم (User Management Panel)**:
   - دسترسی اختصاصی مدیر سیستم (Admin).
   - ساخت اکانت کاربری با تعیین نام، نام کاربری، رمز عبور، و سطح دسترسی (کاربر عادی / مدیر).
   - **مشاهده و فیلتر تسک‌های هر کاربر به تفکیک**: مدیر می‌تواند با یک کلیک کارهای مربوط به هر کاربر را رصد کند.
   - تخصیص مستقیم تسک به هر یک از اعضا در هنگام ایجاد یا ویرایش تسک.
   - جدول آمار عملکرد هر کاربر شامل تعداد کل وظایف، تعداد کارهای انجام‌شده، و نوار درصد پیشرفت.

4. **اصلاح منوی پایین موبایل**:
   - اصلاح کامل چینش و ناوبری نسخه موبایل؛ دسترسی روان به تب‌های داشبورد، تسک‌ها، تمرکز، تقویم و کاربران/آمار بدون تداخل با دکمه ایجاد تسک.
   - قابلیت جابجایی بین نمای شبیه‌ساز موبایل و نمای تمام‌صفحه دسکتاپ در هر زمان.

5. **بک‌اند PHP و سازگاری کامل با IIS (ویندوز سرور)**:
   - فایل پیکربندی کامل `web.config` برای Microsoft IIS (پشتیبانی از URL Rewrite، امنیت فایل‌های پایگاه‌داده و MIME Types).
   - معماری REST API در پوشه `api/` با زبان PHP (`auth.php`, `users.php`, `tasks.php`, `categories.php`, `stats.php`).
   - ذخیره‌سازی داده‌ها با پایگاه داده سبک و پرسرعت SQLite (با قابلیت اتصال به MySQL در صورت نیاز).
   - فایل راهنمای استقرار در IIS ویندوز: `IIS_DEPLOYMENT_GUIDE.md`.

## 💻 نحوه اجرا و استقرار

### ۱. اجرای نسخه توسعه محلی (Live Preview):
```bash
npm install
npm run dev
```

### ۲. استقرار روی سرور IIS ویندوز:
- فایل‌های پروژه را در پوشه سایت IIS قرار دهید (مثلاً `C:\inetpub\wwwroot\taskrooz`).
- ماژول **URL Rewrite** و قابلیت **CGI (FastCGI)** را در IIS فعال کنید.
- مجوز نوشتن (Write) پوشه `data/` را به کاربر `IIS_IUSRS` بدهید.
- جزئیات کامل و گام‌به‌گام در فایل `IIS_DEPLOYMENT_GUIDE.md` شرح داده شده است.
